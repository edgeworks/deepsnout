PILOT GUIDE

Find changes worth explaining.

Compare behavior in context, not an endpoint's lifetime collection of rare indicators.

First run

Try the synthetic demo under Import & demo. Then add a read-only Splunk connection under Sources, test it, poll once and inspect the report before enabling scheduled collection. The connection reads standard Sysmon events already stored in Splunk; no new endpoint agent is needed.

Reference history

Comparisons use previous days, excluding the current UTC day. Defaults: 28 retained days and at least seven observed days. Historical imports older than 24 hours build the reference without generating retrospective findings. The specific execution detector operates during learning.

Evidence and uncertainty

Process relationships use source GUIDs, never recycled PIDs or time proximity. Parent names in Event 1 are reported fields, not independently verified ancestry. Outbound correlation requires a matching endpoint + ProcessGuid and Initiated=true. Missing input lowers capability, not presumed risk.

Investigation

Open a finding, compare current behavior with its reference, examine limitations and source pointers, then record a decision. Evidence remains with unresolved findings after reference expiry. Expected behavior is exact-context and endpoint-scoped with an expiry, not a file or domain allowlist.

Pilot boundaries

No autonomous remediation, enrichment, ML scoring, binary EVTX decoding, direct Universal Forwarder receiving, or full event archive. Future WEF/Elastic transports can reuse normalization. There is no deployment benchmark for thousands of endpoints.

Operations

Monitor queue health, parser failures, deduplication capacity and missing process joins. A source error does not silently advance its checkpoint. Exact fingerprint retention is finite; committed Splunk slices and identical imports have transactional receipts. Back up database and application secrets together.

Privacy

Raw event bodies and full command lines are discarded. Commands become structural flags. Paths redact the user-profile component, but hosts, destinations and other path components can still be sensitive. Keep the workspace restricted.
